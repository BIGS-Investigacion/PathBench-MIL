# BRCA Domain-Shift Analysis Pipeline

This document describes the end-to-end pipeline used to analyse the domain shift between **TCGA-BRCA** (training cohort) and **CPTAC-BRCA** (test cohort) in MIL-based breast cancer classification tasks (ER, PR, HER2, PAM50).

---

## Overview

The pipeline consists of five sequential stages:

```
1. Model training  →  2. Inference  →  3. Representative patch selection
        ↓
4. Domain-shift metrics  →  5. Statistical analysis & figures
```

---

## Stage 1 — Model Training

Models are trained with PathBench using the framework's standard workflow (`main.py`).

**Tasks:** ER, PR, HER2 (binary), PAM50 (5-class)
**MIL aggregators:** `clam_mil_mb`, `dsmil`, `transmil`
**Feature extractor:** Virchow2 (patch size 256 px, 128 µm)
**Normalisation strategies:** `macenko`, `none`
**Config files:** `config/conf_brca_virchow2_test.yaml` (one per task/model, generated by `scripts/old/gen_configs.py`)

Trained model directories follow the convention:

```
experiments/brca_virchow2_test_{task}_{mil}/mil/{idx}-256_128_{norm}_virchow2_{mil}_*/
```

---

## Stage 2 — Inference on TCGA and CPTAC

Each trained model is evaluated on both cohorts (TCGA and CPTAC) under each normalisation strategy.

**Script:** `scripts/old/predict_slides.py`
**SLURM jobs:** `slurm_jobs/job_predict_{task}.slurm`

For each task the job iterates over all (MIL × normalisation) combinations and writes per-slide predictions to:

```
experiments/brca_virchow2_test_{task}_{mil}/mil/{idx}-*/predictions.csv           (TCGA)
experiments/brca_virchow2_test_{task}_{mil}/mil_eval/{idx}-*_cptac/*/predictions.csv  (CPTAC)
```

Each `predictions.csv` has columns: `slide, y_true, y_pred0, y_pred1, ...`

---

## Stage 3 — Representative Patch Selection

For the morphological analysis, 25 representative patches per class per cohort are selected.

**Method:** Top-8 patches per WSI by CLAM-MB attention → pool per class → select the 25 closest to the class centroid (cosine distance in Virchow2 embedding space).

**Script:** `scripts/old/select_centroid_patches_clam_att.py`
**SLURM job:** `slurm_jobs/old/job_select_centroid_patches_clam_att.slurm`

```bash
python scripts/old/select_centroid_patches_clam_att.py \
    --top_k 8 \
    --n_closest 25 \
    --tasks er erbb2 pr pam50 \
    --output_dir results/centroid_patches_clam_att
```

Patch images are saved to `results/centroid_patches_clam_att/`.

---

## Stage 4 — Domain-Shift Metrics

All quantitative domain-shift metrics are computed by a single script:

**Script:** `scripts/collect_metrics.py`

```bash
python scripts/collect_metrics.py \
    [--exp_dir experiments] \
    [--bags_dir /path/to/256_128_none_virchow2] \
    [--output results/per_class_metrics.csv] \
    [--top_k 8]
```

Output: `results/per_class_metrics.csv` — one row per (MIL × task × class), 33 rows total.

### Columns

| Column | Definition |
|--------|-----------|
| `mil` | MIL model: `clam_mil_mb`, `dsmil`, `transmil` |
| `task` | Classification task: `er`, `erbb2`, `pr`, `pam50` |
| `cls_id` | Numeric class index |
| `cls_name` | Class label (neg/pos/Basal/…) |
| `metric` | Metric type: `pr_auc` (ER/PR/HER2) or `f1` (PAM50) |
| `none_tcga` | Per-class metric on TCGA, no stain normalisation |
| `none_cptac` | Per-class metric on CPTAC, no stain normalisation |
| `mac_cptac` | Per-class metric on CPTAC, Macenko normalisation |
| `delta_n` | `mac_cptac − none_cptac` — Macenko gain on CPTAC |
| `rpd` | `(none_cptac − none_tcga) / (−none_tcga)` — relative performance drop TCGA → CPTAC |
| `prev_tcga` | Class prevalence in TCGA (from `y_true`) |
| `prev_cptac` | Class prevalence in CPTAC (from `y_true`) |
| `delta_p` | `prev_cptac − prev_tcga` — prevalence shift |
| `d_c` | Cosine distance between TCGA and CPTAC class centroids in Virchow2 embedding space, averaged across the three MIL models |

### How d_c is computed

For each MIL model and each slide, the top-K patches by attention weight are selected:
- **CLAM-MB**: uses the class-specific attention column (index = ground-truth `cls_id`)
- **DSMIL / TransMIL**: uses the single attention vector

Virchow2 embeddings (`.pt` bags in `bags_dir`) are loaded for the selected patches. The class centroid is the mean of all selected embeddings across all slides of that cohort. d_c is the cosine distance between TCGA and CPTAC centroids for the same class, averaged across the three MIL models.

Requires access to bag files (`.pt`) and attention files (`_att.npz`) — run as a SLURM job for large datasets.

## Stage 4b — Morphological Separability (B̃_c)

### Pathologist annotations

Two pathologists independently scored the 25 representative TCGA + 25 CPTAC patches per class on six histomorphological features: Tubule Formation (ESTRUCTURA GLANDULAR), Nuclear Pleomorphism (ATIPIA NUCLEAR), Mitotic Activity (MITOSIS), Necrosis (NECROSIS), Lymphocytic Infiltration (INFILTRADO_LI), and PMN Infiltration (INFILTRADO_PMN).

**Inter-rater reliability** was assessed with:
- Weighted kappa (linear weights) for ordinal features (Tubule Formation, Nuclear Pleomorphism, Mitotic Activity)
- Cohen's kappa for binary features (Necrosis, LI, PMN)

When one pathologist had a missing score, the other's value was used. The **mean of the two pathologists' scores** is used as the definitive annotation.

**Script:** `scripts/old/interrater_kappa.py`
**Outputs:** `results/interrater_kappa.tex`, `results/representative_images_annotation_mean_input.xlsx` (sheets: TCGA, CPTAC)

### Biological separability matrices

**Script:** `scripts/biological_separability.py`

```bash
python scripts/biological_separability.py \
    [--input results/representative_images_annotation_mean_input.xlsx] \
    [--output_dir results] \
    [--alpha 0.05]
```

For each task group, two matrices are computed:

**B_{c,d}^{TT} (TCGA × TCGA):** Σ|r| of Mann-Whitney U features (two-sided, BH-corrected) that are significantly different between TCGA class c and TCGA class d. r is the rank-biserial correlation (effect size).

**B_{c,d}^{TC} (TCGA × CPTAC):** Same, comparing TCGA class c against CPTAC class d.

From B^{TC}, morphological separability is derived as:

```
B̃_c = min_{d ≠ c} B_{c,d}^{TC} − B_{c,c}^{TC}
```

A positive B̃_c means TCGA class c is more morphologically different from CPTAC classes other than c than from CPTAC class c itself — i.e., the morphology is separable across the domain shift.

**Outputs per task:**
- `results/bio_tcga_tcga_{task}_matriz.csv`
- `results/bio_tcga_cptac_{task}_matriz.csv`

**Summary:** `results/bio_b_tilde.csv` — B̃_c per (task, class)

## Stage 5 — Statistical Analysis and Figures

All statistical modelling and figure generation is handled by two scripts:

### `scripts/old/generate_results_table.py`

Main analysis script. Reads upstream results and produces:

| Output | Description |
|--------|-------------|
| `results/stats_table.tex` | Univariate and multivariate regression table (RPD ~ Δn, d_c, B̃_c, Δp) with BH correction |
| `results/figures/bio_matrix_*.{png,pdf}` | Biological comparison heat maps per task |
| `results/figures/bio_matrix_contrast.{png,pdf}` | Aggregated contrast matrix |
| `results/figures/cm_clam_*.{png,pdf}` | Confusion matrices (CLAM-MB on CPTAC) |
| `results/figures/morph_vs_conf_*.{png,pdf}` | Morphology vs. confusion scatter plots |

Multiple-testing correction uses the **Benjamini–Hochberg (BH)** procedure applied separately within each family of tests (univariate Spearman, univariate OLS slope, multivariate model, collinearity).

The final multivariate model is **RPD ~ Δn + d_c** (B̃_c excluded: p=0.881 in the full model, ΔR²<0.001).

### `scripts/old/plot_univariates.py`

Generates scatter plots with OLS regression and 95% CI bands for each univariate relationship with RPD:

| Output | Relationship |
|--------|-------------|
| `results/univariate_plots.{png,pdf}` | 2×2 panel: RPD ~ Δn, RPD ~ Δp, RPD ~ d_c, RPD ~ B̃_c |
| `results/collinearity_plots.{png,pdf}` | 3-panel: Δn ~ d_c, Δn ~ B̃_c, d_c ~ B̃_c |

## Reproducing the Analysis

```bash
source pathbench_env/bin/activate

# 1. Train models (requires GPU)
python main.py config/conf_brca_virchow2_test.yaml

# 2. Run inference on TCGA and CPTAC (requires GPU)
sbatch slurm_jobs/job_predict_er.slurm
sbatch slurm_jobs/job_predict_pr.slurm
sbatch slurm_jobs/job_predict_erbb2.slurm
sbatch slurm_jobs/job_predict_pam50.slurm

# 3. Collect per-class metrics and centroid distances (requires bag files)
python scripts/collect_metrics.py \
    --bags_dir /home/PARADIS/mama/tfrecords/shared_bags/256_128_none_virchow2
# → results/per_class_metrics.csv

# 4. Select representative patches for pathologist annotation (requires GPU + WSI access)
sbatch slurm_jobs/old/job_select_centroid_patches_clam_att.slurm

# 5. [Manual step] Pathologists score the selected patches
#    Output: results/representative_images_annotation_mean_input.xlsx

# 6. Compute inter-rater kappa and consolidate mean annotations
python scripts/old/interrater_kappa.py
# → results/interrater_kappa.tex
# → results/representative_images_annotation_mean_input.xlsx (updated)

# 7. Compute biological separability matrices and B̃_c
python scripts/biological_separability.py
# → results/bio_tcga_tcga_{task}_matriz.csv
# → results/bio_tcga_cptac_{task}_matriz.csv
# → results/bio_b_tilde.csv

# 8. Generate stats table and biological figures
python scripts/old/generate_results_table.py

# 9. Generate univariate and collinearity figures
python scripts/old/plot_univariates.py
```
